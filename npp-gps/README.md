# GPS Plugin

GPS plugin, allows you to load GPS data from various sources and visualize it within Neon Player. Features include map visualization, path tracking, and integration with other sensor data.

## Installation
For instructions on how to install and manage Neon Player plugins, please refer to the [Neon Player Plugin Documentation](https://docs.pupil-labs.com/neon/neon-player/plugin-api/#adding-a-plugin).

## Usage
1. Use the GPS utility on this repo or a Garmin/Polar export to generate a `.gpx` file from your GPS data.
2. Place the `.gpx` file or the gps.csv in the same directory as your Neon Player recording.
3. Open the plugin and visualize the map.
